# SIRE 2.0 Observation Report — Comment Section Filling Guide

## When to Use

When a SIRE 2.0 inspector raises observations and the vessel needs to fill in the **Comment** section with Immediate Cause / Root Cause / Corrective Action / Preventative Action.

## Structure

### 1. Immediate Cause (直接原因)
**Formula:** `[Person/Action] + [Specific Error] + [Which Document/Requirement]`
- Be SPECIFIC — name the document, officer, exact field/code
- 2-3 sentences max
- NOT generic "lack of awareness"

### 2. Root Cause (根本原因)
3-5 numbered points covering:
1. SMS procedure gap (does the SMS say how?)
2. Process/execution gap (why didn't it work?)
3. Verification gap (who was supposed to catch this?)
4. Training/awareness gap (if applicable)
5. Documentation control gap (if documents misplaced)
- Always cite SMS document numbers (SQI-XXX, CSM-XXX)
- Don't blame people — blame processes
- Include "inspection readiness" gap: procedure exists on paper but was it inspection-ready?

### 3. Corrective Action (纠正措施) — PAST TENSE
Numbered list of actions ALREADY completed:
1. Immediate fix
2. Verification (cross-check everything related)
3. Review with responsible officer
4. Notification to officers/crew

### 4. Preventative Action (预防措施)
Numbered list of SYSTEMIC changes:
1. Template/procedure revision (change SMS)
2. Checklist addition (new mandatory check)
3. Training/toolbox talk
4. Shore-side verification (superintendent)
5. KPI/metric tracking

## Pitfalls
- "improve training" without WHAT/WHOM/WHEN is useless
- Most SIRE deficiencies are documentation/process, not hardware
- Distinguish: procedure exists but not followed (PROCESS GAP) vs no procedure exists (SMS GAP)
- Always include shore-side/superintendent involvement in preventative actions
- Root Cause goes deep; Immediate Cause stays surface
