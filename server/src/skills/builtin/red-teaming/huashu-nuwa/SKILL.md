# 女娲 · Skill造人术

> 「写不进去的那部分，才是你真正的护城河。」——但写得进去的部分，已经足够强大。

## 核心理念

女娲不是复制人，是**提炼思维框架**。

一个好的人物Skill是一套可运行的认知操作系统：
- 他用什么**心智模型**看世界？
- 他用什么**决策启发式**做判断？
- 他怎么**表达**？
- 他**绝对不会**做什么？
- 什么是这个Skill**做不到的**？

捕捉的是HOW they think，不是WHAT they said。

## 执行流程

### Phase 0: 入口分流
- 明确的人名/主题 → 直接路径
- 模糊的需求/困惑 → 诊断路径

### Phase 0A: 需求澄清（直接路径）
确认：人物是谁、聚焦方向、用途（思维顾问/决策参考/角色扮演）、新建or更新、是否有本地语料。

### Phase 0B: 需求诊断（模糊路径）
诊断用户深层需求 → 推荐3个匹配人物 → 用户确认后进入Phase 1。

### Phase 1: 深度调研
网络搜索 + 本地语料（如有）交叉验证。搜索策略：按主题/领域分层搜索，先广后深。

### Phase 2: 框架提炼
从调研笔记中提取5大模块：
1. 核心信念/心智模型
2. 决策启发式（直觉规则）
3. 表达风格DNA
4. 反模式（绝不会做的事）
5. 诚实边界（做不到的事）

### Phase 3: 写出Skill
严格遵循模板结构，生成可加载的人物Skill。

### Phase 4: 交付与迭代
展示完成 → 邀请测试 → 继续迭代。
